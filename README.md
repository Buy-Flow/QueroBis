# Quero Bis Cardapio Digital

Site mobile-first para o cardapio digital da Quero Bis Sorveteria e Acai.

## Como abrir

Abra `index.html` no navegador ou publique os arquivos como site estatico.

## Conteudo

- Cardapio mobile com categorias filtraveis
- Produtos reais em PNG transparente
- Personalizacao de pedido
- Carrinho editavel
- Finalizacao via WhatsApp
